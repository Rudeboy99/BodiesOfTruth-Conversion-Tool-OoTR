  Eglantine ................ Djihads80 and contributors
                             https://github.com/Djihads80/Eglantine
     app\lib\nup.py reads .nup game archives following the container layout
     in Eglantine's src/core/file_sys/nup_container.cpp.

                             NintenTools.Bfres, MIT)

                             GPL-2.0-or-later
                             https://github.com/zeldamods/oead
     app\lib\sdict.py builds Nintendo ResDic dictionaries the same way these
     libraries do.

  Switch Toolbox ........... KillzXGaming and contributors
                             GPL-3.0
                             https://github.com/KillzXGaming/Switch-Toolbox
     Used to inspect models, materials and shader options, and to export
     reference textures while mapping the BFRES and BNTX formats.

  Blender .................. Blender Foundation
                             GPL-2.0-or-later
                             https://www.blender.org
     Used to review meshes, bones and weights during development.

  Lichii ................... zortos293 and contributors
                             GPL-3.0
                             https://github.com/zortos293/Lichii
  Fritchii ................. Frizti
                             https://github.com/Frizti/Fritchii
  Eden ..................... Eden emulator contributors
     Emulators the converted mods and the lens code module (Emulation
     platform) were tested on.

  Longshot / Hookshot ...... NotRexed and contributors
     Recompiled PC versions the Recomp code patch was written and tested
     for. The tests in app\patch\codecave_recomp\test model the behaviour of
     Longshot's a64-kit lift.


--------------------------------------------------------------------------
  4. GAME CONTENT AND TRADEMARKS
--------------------------------------------------------------------------

  No game files, game code or game assets are included. The tool reads
  game files from your own copy of the game, and app\index\npc_index.json is
  a list of model, texture and actor names generated from those files by
  app\index\build_index.py. The GPL covers this tool only; it does not grant
  any rights to the game or to the outfit mods you convert, which stay
  under their own authors' terms.


If you are the author of a project used here and something is missing or
wrong, please get in touch so it can be corrected.
